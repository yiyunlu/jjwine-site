## 推荐 Claude Code 工作方式

单一、边界清楚的任务使用 print mode，并限制工具和轮次；例如：

```bash
claude -p "修复多语言 html lang 与 alternates metadata，补齐测试，并运行 lint 与 test。遵守 CLAUDE.md。" \
  --allowedTools "Read,Edit,Write,Bash" \
  --max-turns 12
```

复杂的设计—实现—浏览器检查循环，再使用独立 tmux 交互会话。每次任务结束后由 Hermes：

1. 检查 Git diff。
2. 独立运行测试和构建。
3. 浏览器验证桌面与移动端。
4. 核对事实声明和三语一致性。
5. 向 Eddie 汇报实际结果；未经要求不提交、不推送、不部署。
