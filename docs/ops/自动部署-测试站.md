# 测试站自动部署（GitHub Actions）

工作流：`.github/workflows/deploy-test.yml`

## 做什么

- 触发：推送到 `main`（仅改动 `*.md`、`docs/**`、`CLAUDE.md`、`.openai/**` 时跳过），或在 Actions 页面手动 **Run workflow**（`workflow_dispatch`，仅允许 `main`）。
- 步骤：守卫检查 → 检查 Secrets → Node 22 → `npm ci` → `npm run lint` → `npm test`（内含 `npm run build`）→ `wrangler deploy --config wrangler.jsonc` → `curl` 冒烟检查。
- 目标：**仅测试站** Worker `jjwine-site` → `https://jjwine.ecomm101.cc`（`wrangler.jsonc` 中的 custom domain）。
- 并发：同一时间只跑一个部署；新的推送会取消仍在进行的旧部署（`cancel-in-progress`）。
- 不做 PR 预览部署；fork 仓库与非 `main` 分支不会执行部署。

## 正式站保护

正式站 `www.jiawine.com` 由公司 IT 托管，**本仓库的任何流水线都不得部署正式站**。工作流的守卫步骤会在以下情况直接失败：

- `wrangler.jsonc` 出现 `jiawine`；
- Worker 名称不是 `jjwine-site`；
- 任何路由 `pattern` 不是 `jjwine.ecomm101.cc`。

## 需要的 GitHub Secrets

仓库 Settings → Secrets and variables → Actions → New repository secret：

| 名称 | 内容 |
|------|------|
| `CLOUDFLARE_API_TOKEN` | Cloudflare API Token（My Profile → API Tokens → Create Token）。最小权限：Account → **Workers Scripts: Edit**、Account → **Account Settings: Read**；Zone → **Workers Routes: Edit**（Zone Resources 只选 `ecomm101.cc`）；可选 User → User Details: Read。Account Resources 只选拥有 `jjwine-site` 的账号。 |
| `CLOUDFLARE_ACCOUNT_ID` | 拥有 Worker `jjwine-site` 的 Cloudflare 账号 ID（账号名 `Yiyun LU`，ID 以 `4b49c4` 开头；完整值可用 `npx wrangler whoami` 或 Cloudflare 控制台右侧栏查看）。 |

未配置 Secrets 时，工作流会在 “Check required secrets” 步骤失败，不会部署。

## 回滚

部署失败不会影响线上旧版本。若新版本上线后有问题：

```bash
npx wrangler deployments list --config wrangler.jsonc   # 查看历史版本
npx wrangler rollback --config wrangler.jsonc            # 回滚到上一个版本
npx wrangler rollback <VERSION_ID> --config wrangler.jsonc  # 回滚到指定版本
```

也可在 Cloudflare 控制台 Workers & Pages → `jjwine-site` → Deployments 中回滚。注意：回滚后下一次推送到 `main` 会再次自动部署最新代码；如需暂停自动部署，可在 Actions 页面对该工作流点 **Disable workflow**，或先在 `main` 上 revert 有问题的提交。
